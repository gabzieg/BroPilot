# Illusion School

This page is about the Wizard subclass. For a list of all spells of this school, see [Illusion](/wiki/Illusion "Illusion").

**Illusion School** is one of the [subclasses](/wiki/Wizard#Level_2 "Wizard") of [Wizard](/wiki/Wizard "Wizard"). These Wizards are specialized in illusory magic that can hide where they are, detect the invisible, or trick enemies into wasting actions.

## Subclass features

*This subclass obtains all the features from its base class, [Wizard](/wiki/Wizard "Wizard"), in addition to its unique features outlined below.*

### Level 2

Illusion Savant
:   Halves the cost to learn Illusion spells from [Scrolls](/wiki/Scrolls "Scrolls"). Learning these spells will only cost **![25 gp](/w/images/thumb/f/f5/Gold_Pile_Single_Item_Image.png/23px-Gold_Pile_Single_Item_Image.png.webp) 25 gp** per spell level.

![](/w/images/b/be/Bg3_content_hr.png)
