# Feats

**Feats** are features that grant a character unique improvements. All classes select one feat at class levels 4, 8, and 12. [Fighters](/wiki/Fighter "Fighter") select an additional feat at level 6; [Rogues](/wiki/Rogue "Rogue") select an additional feat at level 10.

See [D&D 5e feat changes](/wiki/D%26D_5e_feat_changes "D&D 5e feat changes") for an overview of difference between feats in *5e D&D* and *Baldur's Gate 3*.
